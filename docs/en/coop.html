Edit an OMSI 2 map with friends (co-op mode)

Feditor lets several people edit the same OMSI 2 map at the same time, each on their own PC, seeing the others' changes live. It works over the local network and over the internet, with no port forwarding.

Before you start

  • Everyone needs Feditor and OMSI 2 with the same map and the same objects. Use File → Pack map (.zip)… to pass them around.
  • The first time, Feditor asks for network permission; Windows will ask too. Choose Allow.

Create the room (host)

  1. Open the map in edit mode.
  2. Side panel → Session tab → Create room → Invite.
  3. Pick how friends connect:
    • Local network only: same house/LAN, or a VPN such as Radmin, ZeroTier or Tailscale.
    • Online (internet): friends in other houses. Feditor sets up a secure Cloudflare tunnel automatically; the first time takes a few seconds.
  4. Click Copy code and send it to your friends.

Join (guests)

  1. Session tab → paste the code into Join with a code → Join.

Co-op FAQ

QuestionAnswer
Do I need to open router ports?No: Online (internet) uses an automatic tunnel.
My friend can't joinUse Online (internet) if you're not on the same network, and make sure both allowed network access.
Do I see changes live?Yes, everyone sees what the others are doing while editing.
Objects are missingThey don't have the same objects: send them the packed map .zip.

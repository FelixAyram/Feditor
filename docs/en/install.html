How to install Feditor, the free OMSI 2 map editor

Feditor has no installer: it is a .zip you unzip and run. It takes less than a minute and touches neither the Windows registry nor your OMSI 2 installation.

Requirements

  • Windows 10 or 11, 64-bit.
  • Any DirectX 11-class or newer GPU with a current driver (NVIDIA GTX 400+, AMD HD 7000 / RX, Intel HD 4400+).
  • An OMSI 2 installation (Steam or otherwise). Feditor includes no OMSI files.
  • Recommended: 8 GB RAM, SSD, 4+ cores.

Steps

  1. Open Releases and download Feditor-<version>.zip. You don't need “Source code”.
  2. Unzip everything into a folder you can write to, e.g. C:\Games\Feditor. Avoid Program Files.
  3. Run omsi_f4_viewer.exe.
  4. The first time it asks for your OMSI 2 folder: the one containing Omsi.exe (usually C:\Program Files (x86)\Steam\steamapps\common\OMSI 2). It is remembered.
  5. Pick a map, an entrypoint and whether to edit or only view (read-only mode).

If SmartScreen says “Windows protected your PC”

Normal for any new unsigned program: click More info → Run anyway.

Troubleshooting

ProblemFix
Won't start / closes on launchUnzip the whole archive (don't run it from inside the zip) and check logfile.log and crash_report.txt next to the .exe.
Asks for the OMSI 2 folder every timeThe editor folder must be writable.
No DirectX 12 on my GPUFeditor falls back to Vulkan, then WARP. Force it with --gfx d3d12|vulkan|warp or a gfx_backend.txt file next to the .exe.
Low fpsLower tile distance and shadow distance, raise “minimum on-screen size”, reduce AI traffic, update your drivers.

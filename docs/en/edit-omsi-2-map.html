How to edit an OMSI 2 map step by step

With Feditor, a free OMSI 2 map editor, you edit the map directly on the original files: .map tiles, .sli splines, .sco objects and global.cfg. What you save keeps working in OMSI 2 with no conversion.

Before you start: copy the map folder inside OMSI 2\maps. Feditor works on your real map: if you save, it saves.

1. Open the map

  1. Run omsi_f4_viewer.exe and pick your OMSI 2 folder the first time.
  2. Pick the map (its global.cfg) and an entrypoint (where the camera starts).
  3. Choose edit (or read-only, where nothing can be modified).
  4. You can also open a single tile: File → Open .map tile.

2. Move around

OrbitRight mouse button + drag
ZoomMouse wheel
PanMiddle mouse button + drag
SelectLeft click
Undo / SaveCtrl+Z / Ctrl+S
Walk modeF7 (cycles: walk-edit → walk-only → exit)

3. Edit objects and splines

  • .sco objects: click to select, then move, rotate, copy or delete. Selecting one shows its vertices, textures, LODs and the files it uses.
  • .sli splines: roads and paths. Create them from the catalogue or with the spline creator (Tools → Spline creator…), which has a profile, textures and a 3D preview.
  • Tiles and terrain: every tile is a .map; the tile distance is set in View → Graphics.
  • Entrypoints, paths, traffic lights and car parks are editable too.
  • Traffic: click an AI car to inspect or delete it; click a parked car to select its car park. Car park real toggles between real cars and edit boxes.

4. Edit on foot (walk mode)

F7 puts you on foot: WASD to walk, Shift to run, Space to jump. In walk-edit a crosshair appears: click picks an object and carries it, click again or right-click drops it, R rotates, Del deletes, N spawns the catalogue object you are aiming at, E shows the cursor for the panels.

5. Save

Ctrl+S saves your changes in the map. You can keep using the stock OMSI 2 editor on the same map: Feditor complements it.

6. Share the map

File → Pack map (.zip)… bundles the map and everything it uses (objects, meshes, textures, scripts, sounds, splines, AI vehicles) into a .zip ready to share. Base-game and Steam DLC content can be excluded so the package stays small and legal to share.

Feditor — free OMSI 2 map editor and 3D viewer

Feditor is a free, open-source map editor for OMSI 2 (OMSI 2 map editor, OMSI editor, OMSI 2 Karteneditor). It opens OMSI 2 maps as they are — .map tiles, .sli splines, .sco objects, terrain, textures, entrypoints and traffic — renders them with a modern DirectX 12 renderer aimed at 60 fps, and lets you edit them, walk around on foot, drive a bus with the openOMSI vehicle simulation and build maps together with friends in co-op.

Features

  • Full OMSI 2 map editing: move, rotate, copy, delete and create .sco objects and .sli splines; edit tiles, terrain, entrypoints, paths, traffic lights and car parks. Undo (Ctrl+Z) and save (Ctrl+S).
  • Fast streaming renderer: background loading, LODs, on-screen-size culling, textures uploaded to the GPU without freezing the editor.
  • Walk mode (F7): WASD to walk, Shift to run, Space to jump; in walk-edit the crosshair picks and carries objects (click / right-click to drop, R rotate, Del delete, N spawn, E shows the cursor).
  • Drive a bus: pick a bus from your OMSI 2 install; physics, engine, gearbox and sounds come from openOMSI. Stop (< 5 km/h) and press F7 to get off, carry the bus like an object, F7 next to it to get back in. AI traffic and parked cars included.
  • Co-op building: several people edit the same map at once over LAN or the internet (automatic Cloudflare tunnel, no port forwarding).
  • Spline creator: profile, textures and 3D preview for new or existing .sli files.
  • Map packer: zips a map with everything it uses (objects, meshes, textures, scripts, sounds, splines, AI vehicles), optionally excluding base-game and Steam DLC content.
  • Auto-update: tells you when a new version is out, downloads it, restarts.
  • English and Spanish UI, following your Windows language.

Requirements

  • Windows 10 or 11, 64-bit.
  • Any DirectX 11-class or newer GPU with a Windows 10/11 driver (NVIDIA GTX 400+, AMD HD 7000 / RX, Intel HD 4400+). Feditor picks the backend itself: DirectX 12 → Vulkan (vkd3d-proton) → WARP software rendering. Force one with --gfx d3d12|vulkan|warp.
  • An OMSI 2 installation (Steam or otherwise). No OMSI files are included.
  • Recommended: 8 GB RAM, SSD, 4+ cores.

Quick start

  1. Get Feditor-<version>.zip from Releases (you don't need “Source code”).
  2. Unzip it into a folder you can write to, e.g. C:\Games\Feditor (avoid Program Files).
  3. Run omsi_f4_viewer.exe.
  4. On first start pick your OMSI 2 folder (the one with Omsi.exe), then a map, an entrypoint and either edit or read-only mode.

Nothing else to install: the zip ships the Visual C++ runtime, the shaders, fonts, the spline creator and the map packer with their own Python. If SmartScreen warns you, choose More info → Run anyway (it happens with any new unsigned program).

FAQ

QuestionAnswer
Is Feditor free?Yes — free, open source (AGPL-3.0), no ads, no account, no paid edition.
Do I need OMSI 2?Yes, Feditor reads your OMSI 2 installation.
Do edited maps still work in OMSI 2?Yes: it saves the original OMSI 2 formats (.map, .sli, .sco, global.cfg).
Does it replace the stock editor?It complements it: you can use both on the same map.
Is it related to openOMSI?It uses openOMSI's vehicle simulation to drive buses. Separate projects.
Does it run on Linux or Mac?Not officially (it needs DirectX 12). On Linux it may work with Proton/Wine + VKD3D, unsupported.
Does it have viruses?No. The full source is on GitHub and the zip is built from it. Antivirus software is wary of new unsigned binaries.
